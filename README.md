### 📖 Overview
This tool watches your in-game message log using **Optical Character Recognition (OCR)** and automatically logs **Rune** and **Worldstone Shard (WSS)** notifications to a `.csv` file for stats calculation and drop-rate tracking. 

> [!TIP]
> **Built for the Grind:** Super handy for "Rune Andys" farming for currency who want effortless, zone-by-zone drop rate metrics without manual spreadsheets!

---

### 🛡️ 100% TOS Safe & Compliant
> [!IMPORTANT]
> **Zero Memory Reading:** This tool **does not** violate Terms of Service by scraping game memory or reading live game files. It strictly performs visual pattern recognition (OCR) directly from your game screen—nothing more.

---

###  Key Features
*  **Automated Drop Logging:** Detects Runes and Worldstone Shards straight from your in-game chat/message log and exports them cleanly to CSV.
*  **Zone-by-Zone Metrics:** Easily track your RNG and drop efficiency across different farming zones.
* 🛠️ **Fully Customizable:** Add additional target items to the tracking table, build in custom metrics, or partition your logs by day/session *(ideal for streamers tracking daily runs)*.
* 🌐 **Go Localhost Dashboard:** Includes a lightweight **Go binary** that you can compile to manage the OCR script and view real-time drop rates right in your local web browser.
